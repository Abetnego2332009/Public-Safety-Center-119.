# 🚑 Public Safety Center 119 (PSC 119)

Public Safety Center 119 (PSC 119) merupakan sistem informasi berbasis web yang dikembangkan untuk membantu pengelolaan layanan kegawatdaruratan medis pada Dinas Kesehatan Kota Pematangsiantar.

Aplikasi ini dirancang untuk mendukung pengelolaan data operasional dan jadwal petugas PSC 119 agar proses administrasi pelayanan menjadi lebih terorganisir.

## ✨ Fitur Utama

### 1. Dashboard Admin
- Ringkasan informasi operasional.
- Monitoring data pelayanan.
- Informasi aktivitas sistem.

### 2. Manajemen Data
- Pengelolaan data petugas.
- Pengelolaan data pengguna.
- Pengelolaan informasi operasional.

### 3. Manajemen Jadwal Petugas
- Pengaturan jadwal kerja petugas.
- Pembagian jadwal berdasarkan shift:
  - Shift Pagi: 08.00–14.00 WIB.
  - Shift Siang: 14.00–20.00 WIB.
  - Shift Malam: 20.00–08.00 WIB.

## 🛠️ Teknologi

- PHP Native
- MySQL
- HTML
- CSS
- JavaScript
- Bootstrap

## 🎯 Tujuan Pengembangan

Membantu pengelolaan administrasi dan jadwal operasional petugas PSC 119 secara terkomputerisasi sehingga informasi dapat dikelola dengan lebih efektif dan terstruktur.
